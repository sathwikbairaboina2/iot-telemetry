# ADR 0008: Host ports 5370-5373, synthetic routes and OSM raster tiles

Date: 2026-10-04 · Status: accepted

## Decision

- This machine runs many sibling stacks, so this repo publishes only 5370 (MQTT), 5371 (MQTT over WebSockets),
  5372 (DynamoDB Local) and 5373 (web). The compose project and container names start with `iot-telemetry-`.
- Routes in `data/routes/munich.geojson` are generated by `scripts/gen-routes.ts` from a fixed seed: smooth closed
  loops around Munich's centre. The geofence `depot-north` is a hand-written polygon in `data/geofences/`.
- The map uses OpenStreetMap raster tiles with attribution, overridable with `VITE_TILE_URL`.

## What I gave up

- **Road realism.** Vehicles drive smooth loops, not snapped roads. Snapping needs a routing engine or an OSM extract.
- **Offline maps.** The demo needs internet for tiles; markers and alerts still work without them. Heavy use must
  respect the OSM tile usage policy.
